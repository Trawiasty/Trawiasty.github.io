Dlaczego pokaz nie zawsze kończy się odgadnięciem?

Program używa ograniczonej listy popularnych haseł i wybranych zmian. Próbowanie wszystkich kombinacji może zająć bardzo dużo czasu, dlatego pokaz może zatrzymać się po 60 sekundach lub wcześniej po pomiarze wydajności. Nie jest to ocena zabezpieczeń prawdziwego konta.

Program modyfikuje hasła z listy, np. dopisuje cyfry lub zmienia wielkość liter.
Kolejne kombinacje (brute-force)
Program sprawdza ciągi znaków według ustalonej kolejności. Czas zależy od liczby możliwości i szybkości obliczeń.
SHA-256
Funkcja tworząca skrót danych. Tutaj służy do lokalnego pokazu obliczeń; nie oznacza, że tak są chronione hasła w serwisach.
CPU / GPU
CPU to procesor urządzenia, na którym uruchomiono test. GPU to procesor graficzny; w tej aplikacji jego szybkość jest wyłącznie założeniem modelu.
Szacunek
Wynik obliczony z przyjętych założeń, a nie zaobserwowany czas złamania hasła.

Jak działa ocena? Dopasowanie do słownika lub modyfikacji daje wynik „odgadnięte”. Krótkie hasła sprawdzane są przez rzeczywiste obliczanie SHA-256 kandydatów (domyślnie maks. 60 sekund; limit można wyłączyć).

Hipotetyczny model GPU zakłada 100 mld prób/s i losowy alfabet. Rzeczywisty CPU jest mierzony osobno; dla Argon2id bez parametrów nie podajemy czasu.

Ważne: to edukacyjny model offline z szybkim SHA-256, nie symulacja zabezpieczeń serwera (np. Argon2id z solą). Nie wpisuj prawdziwych haseł. Importowany słownik pozostaje lokalnie w tej karcie. Przy dużych słownikach zalecany jest komputer z co najmniej 8 GB RAM.

Trzy metody pokazują różne sposoby zgadywania. Znaleziono oznacza dopasowanie w sprawdzonym zakresie. Nie znaleziono nie jest dowodem bezpieczeństwa hasła.

⏱ Co oznaczają wyświetlane czasy?

Dwa różne scenariusze: pomiar CPU w tej przeglądarce oraz hipotetyczny model GPU. Nie są to wyniki tego samego urządzenia.

CPU · ta przeglądarkaBrak pomiaruUruchom brute-force, aby zmierzyć szybkość rzeczywistych prób SHA-256.
GPU · model hipotetyczny—Przykładowe 100 mld prób/s; nie jest to pomiar GPU ani prognoza dla konkretnego systemu.

Szacunki dla losowego alfabetu nie opisują dobrze haseł przewidywalnych. Brak trafienia podczas demonstracji nie oznacza bezpieczeństwa.

To jest pokaz rzeczywistych prób wykonywanych lokalnie. Licznik opisuje wykonane próby, a nie liczbę prób w prawdziwym ataku na konto. Możesz zatrzymać pokaz przyciskiem „Stop”.
