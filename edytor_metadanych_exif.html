Formatowanie danych do importu

Uwaga: Nie musisz podawać wszystkich pól! Brakujące dane zostaną po prostu pominięte i zachowają swoje dotychczasowe wartości.

1. Format JSON (Zalecany):

{
  "lat": 52.213458,
  "lng": 21.03663,
  "elevation": 87,
  "datetime": "2026-10-19T12:42:44.913Z",
  "artist": "GPX Trail Creator",
  "copyright": "© 2026 GPX Trail Creator",
  "description": "Punkt 18",
  "make": "Smartwatch Simulator",
  "model": "Trail Tracker v1.0",
  "software": "GPX Trail Creator App"
}

2. Format CSV (z nagłówkiem):

lat,lng,elevation,datetime,artist,description
52.213458,21.03663,87,"2026-10-19T12:42:44.913Z","Jan Kowalski","Punkt 18"
Dostępne pola importu:
  • lat / latitude — szerokość geogr.
  • lng / longitude — długość geogr.
  • elevation / alt / altitude — wysokość n.p.m. (metry)
  • datetime / date — data (w tym ISO 8601, ISO z "Z", YYYY-MM-DD itp.)
  • artist, copyright, description
  • make, model, software
